CDN Bundle Smoke Test

Tests the self-contained CDN build with no bundler

What this page tests

This page loads ariontalk.js directly from the widget dist output — the same file that jsdelivr/unpkg serve via CDN. It does not use a bundler or import maps. If the FAB button appears in the bottom-right corner, the CDN build works.

How to verify

Open the browser console and check:

  • No module resolution errors (bare specifier failures)
  • customElements.get('ariontalk-widget') returns the class
  • The FAB button renders and is clickable
